
# Telegram Bot for Car Insurance Sales

Цей проект реалізує бота в Telegram, який допомагає користувачам купувати автострахування. Бот приймає фотографії паспорта та технічного паспорта, розпізнає дані за допомогою Mindee API, пропонує користувачу підтвердити дані та формується страховий поліс у форматі PDF за допомогою OpenAI API.

## Опис функціональності

1. **Привітання користувача**: Коли користувач починає чат з ботом, бот вітає його та запитує надіслати фото паспорту.
2. **Розпізнавання даних з паспорту**: Бот використовує API Mindee для розпізнавання інформації з надісланого паспорту.
3. **Розпізнавання технічного паспорту**: Після паспорту бот запитує технічний паспорт і також проводить його аналіз за допомогою API.
4. **Підтвердження даних**: Користувач підтверджує, чи вірно розпізнані дані.
5. **Калькуляція ціни**: Користувачеві повідомляється фіксована ціна страховки (100 USD).
6. **Страховий поліс**: Якщо користувач підтвердив ціну, бот генерує страховий поліс у форматі PDF і надсилає його користувачу.
7. **Інтелектуальна комунікація**: Всі запити користувача обробляються через OpenAI API для симулювання інтелектуальних комунікацій.

## Технології

- **Node.js**: Серверна частина бота.
- **Telegraf**: Бібліотека для роботи з Telegram Bot API.
- **Mindee API**: Для розпізнавання документів.
- **OpenAI API**: Для генерації тексту та підтримки інтелектуальної комунікації.
- **PDFKit**: Для створення PDF документів.

## Встановлення

### Крок 1: Клонуйте репозиторій

```bash
git clone https://github.com/your-username/car-insurance-bot.git
cd car-insurance-bot
```

### Крок 2: Встановіть залежності

```bash
npm install
```

### Крок 3: Налаштуйте середовище

Створіть файл `.env` у корені проекту та додайте наступні змінні:

```
BOT_TOKEN=your_telegram_bot_token
MINDEE_API_KEY=your_mindee_api_key
OPENAI_API_KEY=your_openai_api_key
```

### Крок 4: Запустіть бота

```bash
npm start
```

## Приклад взаємодії з ботом

1. **Крок 1: Початок взаємодії**
   ```
   User: /start
   Bot: Привіт! Надішліть фото паспорту (звичайного паспорту, не техпаспорту).
   ```

2. **Крок 2: Розпізнавання паспорту**
   ```
   User: Надсилає фото паспорту
   Bot: ✅ Розпізнані дані з паспорту:
         - Ім'я: BOHDAN
         - Прізвище: HOROSHKO
         - Номер паспорта: AA1234567
         - Дата народження: 01-01-1990
   ```

3. **Крок 3: Розпізнавання технічного паспорту**
   ```
   User: Надсилає фото техпаспорту
   Bot: ✅ Розпізнані дані з технічного паспорту:
         - Власник: BOHDAN HOROSHKO
         - Номер авто: AA2425TO
         - Тип ТЗ: B2
         - Рік випуску: 2018
         - Марка, модель: HYUNDAI ELANTRA
         - VIN: KMHD841FBJU634304
         - Місце реєстрації: Kyiv
         - Дата реєстрації: 2022-07-25
         - Термін дії: 2026-07-25
   ```

4. **Крок 4: Підтвердження даних**
   ```
   User: Так
   Bot: Ціна страховки: 100 USD. Приймаєте?
   ```

5. **Крок 5: Генерація полісу**
   ```
   User: Так, приймаю
   Bot: Ваш страховий поліс сформовано. Надсилаю файл...
   Bot: [Поліс у форматі PDF]
   ```

## Відомі помилки та їх виправлення

1. **Помилка "MINDEE_API_KEY не заданий у .env"**:
   Перевірте, чи вказали ви правильний API ключ Mindee в файлі `.env`.

2. **Помилка "OPENAI_API_KEY не вказано в .env файлі"**:
   Перевірте, чи вказали ви правильний API ключ OpenAI в файлі `.env`.
